\section{Implementation}
\label{sec:implementation}

\subsection{Engines and real-time hardening}
The baseline is serial pcl/OpenMP multigrid \ndt{}~\cite{autoware,ndtomp}. The Rust port
exposes the same C ABI and also builds as \texttt{no\_std}; ABI/API substitutability does
not imply closed-loop equivalence. Differential tests cover voxel construction, align,
engine, and node paths. Both engines use autoware\_core commit \texttt{\envCommit}.

The following are explicit constraints, not automatic Rust or \texttt{no\_std} properties:
\begin{itemize}
 \item buffers can be reserved from $P$, \maxnn, and $N_{\mathrm{iter}}+1$; a counting
 allocator verifies zero allocations from the first frame inside that envelope. Exceeding
 capacity grows a buffer rather than rejecting the input;
 \item radius search uses a fixed 64-entry iterative stack, preserves near/far visit order,
 and is differential-tested against a recursive oracle;
 \item linting excludes panicking operations, align takes no locks, and disabled counters
 compile away.
\end{itemize}

\subsection{Neighbor cap and engine-tier fixtures}
The \maxnn=64 cap makes the kernel term finite. Its deployment justification assumes one
leaf per occupied voxel per tile, disjoint tiles, radius equal to voxel size, and centroids
inside their voxels. A search ball then intersects at most $3^3=27$ cells, leaving a
$2.4\times$ margin. Boundary inclusion and floating-point radius comparison remain
assumptions. Real replay observes $K=\realKmaxMax$. Overlapping tiles can exceed 64 outside
these conditions; Rust truncates without an overflow flag, so traces provide only
retrospective evidence of $D$ membership.

\label{sec:impl-fixtures}
Four hand-built engine fixtures isolate hazards: \emph{dense-neighbors} reaches 64 leaves
with eight overlapping corner lattices; \emph{max-iterations} reaches the iteration cap;
\emph{cache-hostile} spreads shuffled queries across a wide map; and \emph{subnormal}
places kernel exponentials in the f64 subnormal range. Counter search composes and exceeds
them. The per-tile $K=8$ value belongs only to the corner-lattice witness, not the analytic
ceiling of 27.

\subsection{Deployment-tier witnesses}
\label{sec:impl-legal}
Production preprocessing downsamples and crops scans, rejects duplicates, limits $P$ to
1500, and assumes disjoint voxel-aligned map tiles. The constructed \emph{legal-worst}
witness satisfies these geometry conditions with $K=8$ and uses non-production
$\epsilon=10^{-10}$ to reach 30 iterations; it is a stress witness, not the $K\le27$
ceiling. An independent legality verifier checks each candidate.

A separate shipped-parameter search produces \emph{legal-osc}, which reaches 30 iterations
at $\epsilon=0.01$ but has $\bar K=\legalOscKbar$. Smooth high-$K$ geometry converges
quickly, while oscillatory rough geometry has fewer neighbors, so no searched input combines
both axes. \emph{legal-worst} remains the slowest measured deployment witness and
\emph{legal-osc} establishes reachability of the iteration cap.
