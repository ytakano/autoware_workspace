Deterministic Cost Search and Cross-Language Validation}

\maketitle

\begin{abstract}
Iterative scan-matching kernels such as the Normal Distributions Transform (\ndt) sit on the
critical path of autonomous-vehicle localization, yet their execution time is strongly
data-dependent, which makes classical static worst-case execution time (WCET) analysis
impractical. We present a hybrid WCET analysis of the align kernel of the Autoware \ndt{}
scan matcher (map construction, preprocessing, and ROS scheduling are out of scope), built
around a high-fidelity Rust port of the production C++ engine, work-equivalent to it on
individually certified inputs. We establish a parametric bound on the algorithmic
\emph{work} and empirically characterize the \emph{time per unit of work}; we do not claim
a certified hard time bound on the evaluated platform. Deterministic algorithmic cost
counters, compiled to zero overhead when disabled, serve both as automatically checked
evidence for the work bound and as a platform-independent fitness function for a search for
counter-extremal inputs. Each discovered input is carried verbatim to the uninstrumented
C++ engine, with equal work certified per input. The search exactly saturates the analytic
bound on the number of kernel evaluations per align, and a controlled sweep shows the bound
is affine in the scan size. A two-tier formulation separates the bounded-neighbor engine
tier from the preprocessing-reachable one
($\legalWorstRatioRust\times$--$\legalWorstRatioCpp\times$ apart on measured fixtures),
quantifying the value of input-contract validation at the component boundary. On a
57-minute urban capture (\realOnMap{} on-map matching aligns), the per-input certification
exposed, and led us to fix, two port-fidelity gaps invisible to synthetic fixtures
(\realDivergences{} residual divergent frames). The Rust port meets or beats the C++ engine's observed maximum on every fixture,
while eliminating the C++ engine's ${\approx}\allocPerPtPass$ heap allocations per point
per derivative pass.
\end{abstract}
